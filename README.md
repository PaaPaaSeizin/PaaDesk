# PaaDesk

スマホを自作 Stream Deck 化するシステム。Windows PC 側でボタン配置を編集し、Android を USB 接続して使う。

## 動作環境

- **PC**: Windows 10/11 (x64)
- **スマホ**: Android 7.0 以上 (USBデバッグ必須)

PC 側は常時情報を送信するため、ある程度のスペックが必要。私の環境での動作確認では Ryzen 7 5700X で難なく動作、i5 7200U では定期的に応答なしになる。古い CPU では非推奨。

## 機能

### ボタン
- グリッドエディタ（列・行・サイズ可変）
- ドラッグ&ドロップで並べ替え・画像割り当て
- ボタン背景のズーム / 位置調整
- ボタン背景色 + 透明度
- PNG 透過対応

### アクション
- アプリ / ファイル起動
- キー操作（全キー対応、キャプチャダイアログ付き）
- テキスト入力
- HTTP リクエスト
- ページ切替
- OBS 操作（コード実装済み、動作未検証）
- マクロ（未検証）

### 情報タイル
ボタングリッド内に動的な情報表示を配置できる。タップしてもアクションは実行されない。

対応ソース: CPU 使用率 / CPU 温度(動作しない可能性あり) / メモリ / ストレージ / ネットワーク / OBS / Web 監視 / 時計

文字サイズと任意画像を設定可能。

### その他
- 新規デバイス接続時の APK 自動インストール
- タスクトレイ常駐 / Windows 起動時自動起動
- 無操作フェード（画面を暗転）
- 即時自動保存 / 自動適用

## 構成
pc-app/ Electron アプリ ADB
android-app/ Android アプリ (Kotlin)

通信は USB 経由の TCP + 改行区切り JSON。
